# drum-bass

A personal drum trainer for an Alesis Nitro Max e-drum kit. Android PWA that shows what to hit and when, on a kit layout that mirrors the real one.

- Configurable kit (choose pieces, drag and drop, lock)
- Falling-lane and kit-view display modes
- Songs from user-imported Clone Hero charts and MIDI files
- Backing audio: full mix, no drums, or drums only
- Practice tools: tempo, loop, wait mode

See `SPEC.md` for the full plan and `docs/` for hardware notes and agent roles.
